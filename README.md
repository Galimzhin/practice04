# Практическая работа №4. Наследование, интерфейсы и полиморфизм

- **Вариант:** А · Воин (Алия: 4 ячейки, лимит 6000 г, здоровье 120; Меч, Щит, Зелье)
- **JDK:** OpenJDK 21.0.12 (`java -version`)
- **Maven:** не используется. Пакет `kz.javaworkshop`.

## Структура

```
practice04/
├── src/kz/javaworkshop/
│   ├── Item.java        абстрактный класс: имя, масса, стоимость, describe(), attackBonus(), defenceBonus()
│   ├── Weapon.java      урон 1–100, переопределяет attackBonus() и describe()
│   ├── Armor.java       защита 1–100, переопределяет defenceBonus() и describe()
│   ├── Potion.java      лечение 1–100, реализует Usable
│   ├── Food.java        лечение 1–100, реализует Usable
│   ├── Usable.java      интерфейс: void use(Hero hero)
│   ├── Inventory.java   рюкзак: Item[], add/get/remove/snapshot
│   ├── Hero.java        здоровье, attackPower(), defencePower(), takeHit(), heal(), useItem()
│   └── Main.java        контрольный проход (шаг 6) и проверка границ (шаг 7)
└── README.md
```

Вклад предмета в атаку и защиту считает сам предмет (полиморфизм). `Hero` проверяет
только интерфейс `Usable`; это единственный `instanceof` в проекте.

## Сборка и запуск

PowerShell (из папки `practice04`):

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
chcp 65001
java -cp out kz.javaworkshop.Main
```

Linux / macOS:

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out kz.javaworkshop.Main
```

## Проверки границ (шаг 7)

Три проверки на выбор (все сценарии шага 7 выполняются в `Main`):

```
[3] Удар 5 при защите 8: потеря 0, HP 50/50
[4] Удар 1000: потеря 50, HP 0
[7] Weapon урон 101: IllegalArgumentException (Урон: 1-100)
```

Остальные сценарии (пустой рюкзак, зелье при полном HP, лечение при HP 0, `useItem` для брони,
`maxHp` 0/1001, удар −1, имя из пробелов в `Food`) тоже выводятся при запуске `Main`.
